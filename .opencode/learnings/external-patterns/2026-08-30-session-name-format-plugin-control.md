# Session name format is plugin-controlled (DIA-260830-3q7e)

## Finding (from @ai-specialist gate ai--1)
- The session display name "New session - <ISO> [<word-pair>]" is produced by
  `.opencode/plugins/needs-input-observer.ts`, NOT by any config setting.
- The "New session -" prefix is hardcoded in the OpenCode runtime binary; cannot be
  removed via config.
- The [word-pair] (e.g. [crisp-wren]) is generated by `sessionWordPair()` (FNV-1a hash
  of session ID) in the same plugin (lines 108-121). 100x100 = 10k combos.
- Two code paths append the suffix: `renameDefaultTitle()` (lines 972-976) and the
  `session.created` handler (lines 1166-1170). They duplicate the same logic (DRY violation).

## Change required (developer-approved: hardcode minimal diff)
To drop "New session -" and lead with [word-pair], edit 4 sites in needs-input-observer.ts:
- renameDefaultTitle() (972-976): strip default via regex /^New session - \d{4}-\d{2}-\d{2}T/, format as `[pair] baseTitle`
- session.created handler (1166-1170): same
- notify() attribution (861-863): endsWith -> startsWith
- dedupe regex (970, 1164): suffix-anchor -> prefix-anchor /^\[[a-z]+-[a-z]+\]/
- Update tests: needs-input-observer.dia189.test.mjs, needs-input-observer.platform-gate.test.mjs

## Evidence
- .opencode/plugins/needs-input-observer.ts (lines cited)
- No titleTemplate/title setting exists in opencode.jsonc / oh-my-opencode-slim.jsonc / tui.json
