# DIA-002 — .npmrc shamefully-hoist=true antipattern

- **ID**: DIA-002

- **Area**: js-tooling
- **Severity**: Minor
- **Status**: FIXED
- **Discovered**: inventory (audit-plan m1) · 2026-08-02

---

## Description

`.npmrc` contains `shamefully-hoist=true`. This flattens all dependencies into the
root `node_modules` — an antipattern that masks missing peer/transitive declarations
and pollutes resolution for packages. It is unaddressed since the audit plan (m1).
Evaluation is required: either remove it and fix the fallout, or document why it is
required (e.g. legacy tooling in author-studio/quasar stack).

## Verification

1. Read `.npmrc` and confirm the flag.
2. Attempt `pnpm install --config.shamefully-hoist=false` (or temporarily remove the
   flag) and run `pnpm verify:js` to observe failures — evidence for either fix or
   keep-and-document.

## Fix

`c28a57d` removed `shamefully-hoist=true` from `.npmrc` and documented the rationale
in an in-repo `.npmrc` comment.

## Re-verify

Removal proven green on host **and** container with `turbo --force`; `pnpm-lock.yaml`
is byte-identical after reinstall; the only undeclared import that stays hoisted
(`typescript-eslint`) is pinned via `public-hoist-pattern`; the `.npmrc` comment
documents why the exception remains.
