## Description

The project `.opencode/dcp.jsonc` defines `modelMaxLimits` for 14 models at 50% and
`modelMinLimits` at 12–30%, while the global DCP config is sparse (few/no model
limits). Disparity means the same model gets different cost protections depending on
where the session runs. Unify the global DCP with the project limits (or document why
they intentionally differ).
