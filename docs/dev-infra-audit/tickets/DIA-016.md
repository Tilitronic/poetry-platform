## Description

The project `.opencode/dcp.jsonc` defines `modelMaxLimits` for 14 models at 50% and
`modelMinLimits` at 12–30%, while the global DCP config is sparse (few/no model
limits). Disparity means the same model gets different cost protections depending on
where the session runs. Unify the global DCP with the project limits (or document why
they intentionally differ).

## Verification

1. Read `.opencode/dcp.jsonc` and the global `~/.config/opencode/dcp.jsonc`.
2. Diff the model limit sets.

## Fix

**Intentional divergence** — the global `dcp.jsonc` is a generic fallback for
sessions outside the project; the project `.opencode/dcp.jsonc` (14 models) governs
when running in the repo. No change required.

## Re-verify

Closed as intentional: global DCP remains a thin generic fallback; project DCP
overrides it in-repo — disparity is by design.
