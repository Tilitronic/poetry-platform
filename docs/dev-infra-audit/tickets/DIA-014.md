## Description

`secrets/README.md` advises keys be non-empty (and chmod 600, while files actually
have default perms), but 4 of the 5 key files (`anthropic`, `exa`, `github`, `openai`)
are 0-byte empty placeholders; only `context7_api_key` (44B) is real. The smoke probe
skips mount checks when the host file is empty, so the contradiction is silent.
Either document that empty placeholders are by design, or remove placeholders /
enforce the README rule.

## Verification

1. `git ls-files secrets/` → only `secrets/README.md` tracked.
2. `wc -c secrets/*` → confirm 4 × 0-byte, 1 × 44B.
3. Confirm smoke test skip logic for empty files.
