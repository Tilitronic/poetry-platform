- **Area**: tests-infra
- **Severity**: Major
- **Status**: FIXED
- **Discovered**: fix-lane (wave 2) · 2026-08-02

---

## Description

`make test-infra` was red: bats test 50 failed. The root cause: `verify-pre-push.sh`
line 34 invokes `bash -lc`, which re-sources the login shell profile and rebuilds
`PATH` from the user environment — shadowing the fake `pnpm` that the test injected
into the test PATH. The test therefore resolved the real (or missing) pnpm instead
of the hermetic stub, making the pre-push gate test non-deterministic and dependent
on the host shell profile. Major because a gate suite (and the clean cycle) is red.

## Verification

1. `make test-shell` (or `make test-infra`) → test 50 fails with pnpm not found /
   wrong binary.
2. Inspect `scripts/verify-pre-push.sh:34` (`bash -lc`) and the test's PATH
   injection to confirm the shadowing.

## Fix

`d96b8e4` made test 50 hermetic: the test now runs with a temporary `HOME` (and
isolated profile) so `bash -lc` in `verify-pre-push.sh:34` cannot shadow the fake
`pnpm` from the user's login profile. The same commit synced the
`lint-python-files` bats fixture for the DIA-013 package list (parallel-lane
reconciliation).

## Re-verify

`make test-shell` → **54/54 tests pass**. `make test-infra` (test-shell gate) is
green; no skipped/failing suites.
