## Description

The global `~/.config/opencode/oh-my-opencode-slim.jsonc` did not deny
`openspec-propose` to the orchestrator in any of its 3 presets (opencode-go, cebula,
free). `scripts/test-interview-enforcement.sh` check 1 asserts the orchestrator
denies `openspec-propose` (interview-first spec authoring must go through
`@openspec-plan`); with the denylist missing globally, sessions running under the
global config bypass the enforcement and can author specs directly. Minor hygiene —
no gate failure — but it silently weakens the OpenSpec workflow guard.

## Verification

1. Read the 3 presets in `~/.config/opencode/oh-my-opencode-slim.jsonc` → no
   `openspec-propose` in denied skills.
2. `bash scripts/test-interview-enforcement.sh` check 1 (orchestrator denies
   `openspec-propose`) → fails on the global config path.

## Fix

`13fc7bd` added `!openspec-propose` to the orchestrator denied-skills list in all 3
presets of the global `oh-my-opencode-slim.jsonc` (backup preserved as
`.bak-20260802`). The in-repo `.opencode/CHANGELOG.md` entry from the same commit
registers the F3 audit record.
