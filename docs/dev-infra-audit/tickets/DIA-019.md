- **ID**: DIA-019

- **Area**: opencode-config

- **Status**: FIXED
- **Discovered**: fix-lane (wave 2) · 2026-08-02

## Description

`.opencode/skills/book-rag/SKILL.md` (8 references) and `.opencode/commands/rag.md`
(1 reference) pointed at `~/.config/opencode/scripts/query_rag.py`, a path that does
not exist — the backing script lives in the repo at `.opencode/scripts/query_rag.py`.
Any `rag` invocation (skill activation or `rag` command) resolves a nonexistent
script, so the book-RAG workflow is broken for fresh environments where the global
scripts directory is absent. Major because the reference path is wrong and breaks a
working developer workflow, not just a doc nit.

## Verification

1. `grep -n query_rag .opencode/skills/book-rag/SKILL.md` → expect `~/.config/opencode/...` refs.
2. `grep -n query_rag .opencode/commands/rag.md` → expect same.
3. Confirm the real script exists at `.opencode/scripts/query_rag.py`.

## Fix

`dff4ac9` rewrote all 9 references (8 in `book-rag/SKILL.md` + 1 in
`commands/rag.md`) from `~/.config/opencode/scripts/query_rag.py` to the
repo-relative `.opencode/scripts/query_rag.py`, matching where the script actually
lives.

## Re-verify

`grep -rn "config/opencode/scripts/query_rag" .opencode/` → no matches. Every
reference now reads `.opencode/scripts/query_rag.py` (verified in
`.opencode/skills/book-rag/SKILL.md:38,107-108,173,199-201,348,352` and
`.opencode/commands/rag.md:57`), and the target file exists.
