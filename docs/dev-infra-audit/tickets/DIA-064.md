## Description

**Summary:** commit `2e0c4f3e6cacb3d3120f6c5db44ea21f18e724da` changed 7 agent model
assignments in the `cebula` preset from `deepseek-v4-flash` to `deepseek-v4-pro`. DIA-062
later reverted only the orchestrator to flash (as a single-string `"opencode-go/deepseek-v4-flash"`,
missing the `opencode/deepseek-v4-flash` fallback). The remaining 6 agents (coder, conspecter,
resource-manager, memory-manager, code-navigator, researcher) still had pro models — a
cost-critical leak across nearly all cebula-operational agents.

The developer approved Option A: full revert of all 7 agents back to their pre-commit,
all-flash state.

**Why Critical:** flash models are ~5-10x cheaper than pro models. Six of seven
cebula agents were running on pro rates — every delegation, every conspecter synthesis,
every code-navigator search, every researcher web-fetch was incurring unnecessary cost.

**Revert target commit:** `2e0c4f3e6cacb3d3120f6c5db44ea21f18e724da` (parent, pre-commit state).
