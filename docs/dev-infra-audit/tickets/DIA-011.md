# DIA-011 — openspec version skew between docker images

---

- **ID**: DIA-011
- **Title**: openspec version skew tools/opencode-docker 1.6.0 vs Dockerfile.dev 1.7.0
- **Area**: docker
- **Severity**: Major
- **Status**: OPEN
- **Discovered**: inventory N4 · 2026-08-02

---

## Description

`tools/opencode-docker/Dockerfile` pins `openspec 1.6.0` while `Dockerfile.dev` pins
`openspec 1.7.0`. Inventory notes 1.6.0 is the "false-green version" the smoke test
guards against — i.e. 1.6.0 can report a false pass for gates that 1.7.0 fixed.
Anyone using the `tools/opencode-docker` image (podman, read-only) audits against a
stale binary. Unify both images on 1.7.0 (or document the divergence if intentional).

## Verification

1. `grep -n openspec tools/opencode-docker/Dockerfile Dockerfile.dev` → confirm skew.
2. Note the smoke test (`scripts/test-docker-smoke.sh`) asserts openspec 1.7.0.
