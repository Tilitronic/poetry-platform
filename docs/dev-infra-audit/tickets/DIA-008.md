# DIA-008 — .husky/pre-commit untracked — hook vanishes on clone

---

- **ID**: DIA-008
- **Title**: .husky/pre-commit untracked — hook vanishes on clone
- **Area**: git-hooks
- **Severity**: Critical
- **Status**: CLOSED
- **Discovered**: inventory N1 + baseline `git status` · 2026-08-02

---

## Description

`git status` shows `.husky/pre-push` staged but `.husky/pre-commit` **untracked**.
Because `core.hooksPath = .husky/_` scaffolding is gitignored and regenerated by
`pnpm prepare`, the untracked `pre-commit` hook is not part of the commit set — a
fresh clone (or `pnpm prepare` regeneration) will not restore it. Result: the
pre-commit gate (lint-staged via `scripts/verify-pre-commit.sh`) silently disappears,
and commits bypass the autofix gate. Critical because a gate can vanish with no error.

## Verification

1. Run `git status --porcelain .husky/` and `git ls-files .husky/`.
2. Confirm `pre-commit` is untracked / not in `git ls-files`.

## Fix

**Resolved by baseline commit `6ba7200`** — the `git add -A` in that commit swept
the untracked `.husky/pre-commit` into the index, so the hook is now part of the
commit set and survives clones/regeneration.

## Re-verify

Closed as resolved: `git ls-files .husky/` includes `pre-commit`; the hook no longer
vanishes on clone or `pnpm prepare` regeneration.
