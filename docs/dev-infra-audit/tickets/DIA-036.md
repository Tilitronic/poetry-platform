## Description

The orchestrator agent was delegation-only in write terms (`edit/write/bash` denied)
but had **unrestricted repo reads** (flat `read/glob/grep: allow`). That allowed the
orchestrator to answer codebase questions itself instead of delegating, and there was
no session-continuity mechanism: a fresh orchestrator instance had no memory of prior
delegation results or the audit campaign state. Minor because it does not break any
automated gate, but it weakens the delegation-only operating model and risks context
overflow mid-campaign.

## Verification

1. Read `.opencode/opencode.jsonc` `agent.orchestrator.permission` → confirm flat
   `read/glob/grep: allow` present and no path-scoped `read`/`edit` blocks.
2. Confirm no `.opencode/session/` scaffolding and no `docs/dev-infra-audit/NEXT-RUN.md`.

## Fix

- `.opencode/opencode.jsonc` — orchestrator permission block rewritten: `read` and
  `edit` are now path-scoped (`read` → `.opencode/session/*` + `docs/dev-infra-audit/NEXT-RUN.md`
  - `AGENTS.md` + `.opencode/practice-protected.md`; `edit` → `.opencode/session/*`
    only; `edit` covers write+apply_patch per OpenCode docs so the flat `write` key was
    removed), `glob` path-scoped to `.opencode/session/*`, `grep` denied. Orchestration
    tools unchanged (task/cancel_task/list/lsp/question/wait_for_user/todowrite/skill/websearch).
- `.gitignore` — added `.opencode/session/` (transient orchestrator state, regenerated
  per session, never committed).
- `docs/dev-infra-audit/NEXT-RUN.md` — new operating manual: boot sequence, operating
  rules (read/write restrictions, messages-log discipline, self-rerun at >=50% context,
  delegation map, strict workflow), audit rerun flow (7 gates), open tickets to close
  (DIA-003/006/007/030/034), clean-cycle definition, session continuity.
- `.opencode/oh-my-opencode-slim.jsonc` — all 3 presets (opencode-go, cebula, free)
  orchestrator blocks got a compact "Orchestrator Operating Rules" prompt paragraph.
- `.opencode/CHANGELOG.md` — prepended dated entry documenting the change.
- `.opencode/session/` — scaffolded `messages.md` (starting row recording this change)
  - `HANDOFF.md` template (gitignored, not committed).
