# DIA-015 — pnpm missing from Volta toolchain; JS gates exit 126

---

- **ID**: DIA-015
- **Title**: pnpm missing from Volta toolchain + empty node_modules → pnpm JS gates exit 126
- **Area**: env
- **Severity**: Blocker
- **Status**: RESOLVED
- **Discovered**: baseline run (`pnpm verify` / JS lane) · 2026-08-02

---

## Description

The baseline run of the JS lane failed hard: `pnpm` is not installed on the host
Volta toolchain, and `node_modules` is empty — every `pnpm …` gate (`verify:format`,
`verify:js`, `verify:js-tests`, and the JS portions of `verify`) exits **126**
(command not found / cannot execute). This blocks the entire JS gate set and therefore
blocks the clean cycle. **Environment repair is tracked separately**; this ticket
tracks the gate status until the environment is restored and the lane is re-verified.

## Verification

1. `command -v pnpm` → expect not found on host.
2. `ls node_modules` → expect empty/missing.
3. `pnpm verify:js` (or any pnpm gate) → expect exit 126.

## Fix

**Toolchain repair (environment, tracked separately)**: `volta install
pnpm@10.33.0` + `pnpm install --frozen-lockfile` restored the host toolchain and
`node_modules`.

## Re-verify

All JS gates unblocked: `pnpm verify` (format / js / js-tests) and the JS portions
of `verify` run to completion — no more exit-126 command-not-found failures.
