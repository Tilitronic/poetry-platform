# DIA-029 — no Python lockfiles

---

- **ID**: DIA-029
- **Title**: no Python lockfiles
- **Area**: deps
- **Severity**: Medium
- **Status**: FIXED
- **Discovered**: fix-lane (wave 2) · 2026-08-02

---

## Description

Neither `apps/api-server` nor `packages/analytics-pipeline` committed a lockfile, so
Python dependency resolution was non-reproducible: `uv sync` / pip installs could
drift between runs and machines, and `make audit-python` (DIA-028) had no locked
set to audit. Medium because the Python toolchain cannot be reproduced or audited
deterministically without a lockfile.

## Verification

1. `ls apps/api-server/uv.lock packages/analytics-pipeline/uv.lock` → both absent.

## Fix

`e9781ff` committed `uv.lock` for `apps/api-server` (42 packages) and
`packages/analytics-pipeline` (21 packages), generated via `uv lock`.

## Re-verify

`uv lock --check` passes in both packages (lockfile in sync with
`pyproject.toml`); both `uv.lock` files are tracked in git.
