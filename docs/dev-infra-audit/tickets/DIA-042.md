## Description

With the stack up (restored with `make up` after the DIA-041 `make test-infra`
run, which ends with the stack down), run Playwright browser flows against the
apps per the **playwright-browser** skill. The goal is real user paths, not just
the HTTP-200 probes the Docker smoke test performs:

- **author-studio** — host port 9000 (per smoke-test probe).
- **publishing-platform** — host port per the `docker-compose.yml` ports mapping
  (confirm at run time; compose maps 9000/8000/3000).

Playwright + browsers are installed inside the dev container
(`PLAYWRIGHT_BROWSERS_PATH=/opt/ms-playwright`), so flows run via
`docker compose exec`. Inventory §9: "Playwright: skill only; no committed E2E
test files" — flows are ad-hoc per the skill, results reported per app.

**Depends on DIA-041** (stack must be up; DIA-041's runtime note calls this
out).
