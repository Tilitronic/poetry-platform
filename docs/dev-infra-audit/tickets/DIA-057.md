## Description

**Summary:** research request m0001 ("silent session-logging") dispatched
@ai-specialist (ai--1) + @researcher (res-1), which returned findings
in-conversation only. NO `knowledge/res*/sources/` + conspect +
`shelf.conspects` entry was produced at research time — violating §11
knowledge-workflow order (research → conspect → analysis). The analysis
(ana007) was authored BEFORE the conspect existed; the owner flagged the gap
(m0023); the conspect was then built postfactum (res002, 10 archived sources,
6 synthesis sections, MLA-cited, 2026-08-06) and ana007 was re-grounded
against it.

**Root cause:** routing gap — research lanes persisted findings only in
conversation; the orchestrator did not verify knowledge artifacts (sources/ +
conspect + shelf entry) at research completion. No @conspecter step was
dispatched at research time, so the conspect requirement was never enforced
before analysis started.

**Secondary finding:** the analyzer runtime has NO general file-write tool (no
`write`; `ast_grep_replace` is unreliable on markdown bold-colon nodes) →
analyzer doc persistence must fall back to coder lanes (documented in the
ana-3 stop-report). This makes the analyzer structurally unable to author
knowledge artifacts itself, reinforcing the need for the @conspecter step to
run before analysis.

**Impact:** low severity (no production risk, no gates broken) but a
recurring-process risk — without the conspect gate, analyses can be authored
on un-archived, conversation-only research and cannot be re-grounded or
cited, undermining the knowledge base's traceability contract.

**Linked artifacts:** m0001 (campaign), ana007 (re-grounded report), res002
(conspect), DIA-051 (adjacent JSONL-leak backlog ticket — same
session-logging area).
