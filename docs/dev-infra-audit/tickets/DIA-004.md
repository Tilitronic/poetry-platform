- **Area**: opencode-config
- **Severity**: Minor

## Description

The assembled system prompt contains duplicate/overlapping agent definitions:
`explorer` vs `code_explorer` and `oracle` vs `code_architect`. This stems from
native OMO aliases being renamed in the C4 pass while vendored/config agent entries
still reference the old names. Duplicates bloat context and create ambiguous
delegation targets.

## Verification

1. Inspect `.opencode/oh-my-opencode-slim.jsonc` `disabled_agents` and the active
   agent list — inventory records `disabled_agents [oracle,fixer,explorer,librarian]`.
2. Grep the config bundle for both names in each pair and confirm both are present.

## Fix

**Resolved** — the duplicate/overlapping agent definitions were removed; the only
residual is a stale string mention in `memory-shelf.yaml` (reference-only, no
functional impact).

## Re-verify

Closed as resolved: no duplicate agent definitions remain active in the assembled
system prompt; residual stale string in `memory-shelf.yaml` is documentation-only.
