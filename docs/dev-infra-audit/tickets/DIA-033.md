## Description

Three pre-existing pytest failures in `.opencode/scripts/test_query_rag.py`:
`test_unknown_hashtag`, `test_hashtag_with_digits`, and `test_hashtag_with_underscore`
failed against `query_rag.py`. Root causes: the hashtag regex used `re.match`
(anchored at string start) instead of `re.search`, the tag extraction stripped more
than the `#` token (breaking `#rust`-style tags with digits/underscores), and an
unknown tag was not falling back to the global knowledge base. Minor because the
failures are in a helper script's unit tests, not a main gate — but they kept the
Python test count red (recorded in the F3 audit).

## Verification

1. `cd .opencode/scripts && pytest` → 3 failures (`test_unknown_hashtag`,
   `test_hashtag_with_digits`, `test_hashtag_with_underscore`).

## Fix

`6eba89d` fixed `query_rag.py`: `re.match` → `re.search`, tag extraction strips only
the `#` token, and unknown tags now fall back to the global KB.

## Re-verify

`cd .opencode/scripts && pytest` → **71 passed / 0 failed** (the 3 previously-failing
tests now green).
