# DIA-024 — turbo.json dead compile:lezer pipeline

---

- **ID**: DIA-024
- **Title**: turbo.json dead compile:lezer pipeline (no script, no \*.grammar)
- **Area**: js-tooling
- **Severity**: Major
- **Status**: FIXED
- **Discovered**: fix-lane (wave 2) · 2026-08-02

---

## Description

`turbo.json` declared a `compile:lezer` task with a `dependsOn` edge, but the
pipeline references a script that does not exist in any package (`pnpm` script
`compile:lezer`) and a grammar source type (`*.grammar`) that no package contains.
Turborepo would either fail resolving the phantom task or silently carry a dead
pipeline edge; either way the turbo graph describes work that is not real, masking
misconfiguration and producing confusing task lists. Major because the JS build
graph is misconfigured.

## Verification

1. `grep -n "compile:lezer" turbo.json` → task + dependsOn present.
2. `grep -rn "compile:lezer" apps packages --include='package.json'` → no script.
3. `find . -name '*.grammar'` → no files.

## Fix

`cfbfc54` removed the dead `compile:lezer` task and its `dependsOn` edge from
`turbo.json` — the pipeline now only contains tasks that map to real scripts.

## Re-verify

`turbo.json` no longer references `compile:lezer` (task or dependsOn). `pnpm turbo
run ...` / `pnpm verify` resolve cleanly — every declared task maps to an existing
package script.
