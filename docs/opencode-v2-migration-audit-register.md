## 4. Agreements and disagreements

- Agree: plan not safe to execute as written; the protected-path gate as specified is broken (AUD-B2 + ARC-2); config conversion must not precede a live V2 runtime (AUD-B1 + ARC-3); `.opencode/plugins/` must change for V2 discovery and consolidate to one stable plugin id (AUD-M5 + ARC-1); session-analytics.sh is dead on the V2 CLI (AUD-m4 + ARC-5); keep only a minimal in-plugin ask-timeout watchdog, with corrected APIs and without the waiting marker (AUD-M2 + ARC-6); neither review passed any artifact it rejected.
- Architect went further: the full slice-graph reorder (corrected spine plus the named file collisions), plugin consolidation elevated to a Q1 verdict with the ctx.storage namespace rationale, the discovery hazard confirmed as V2 behavior instead of a probe item, gate placement settled as a layer proof (execute.before runs before permission.assert; wrong layer at design.md:74 and tasks.md:293; lib/routing-gate.ts:88 reads S2.2-deleted rows), the fail-open `* allow *` fallback framing (Q4), the seam deletions (Q5), and the ADR 11/ADR 15 requirement (Q8).
- Auditor went further: the four hard-failing validators as a standalone blocker (AUD-B4) plus the vacuous-pass pair (AUD-m3); the subagent always-background execution break (AUD-B3); the concrete watchdog API-shape errors (AUD-M2); config-schema details agent vs agents and hex color (AUD-M1); the removed `opencode db` and `opencode stats` CLIs (AUD-m4) and the wrong `opencode debug agent` spelling (in AUD-B1); overnight read/edit `.worktrees/*` and TUI `--auto` (AUD-M4); the `@opencode/cli` misreading (AUD-M6).
- Conflict (recorded, not resolved): `@opencode/cli` - ARC-7 calls it "unverified for V2" and demands a verified release artifact + SHA256; AUD-M6 says docs-cli-commands.md:18 documents `npm install --global @opencode/cli` as the official V2 channel and the design's premise is a misreading.
- Conflict (recorded, not resolved): pending-request surfaces - ARC-6 justifies deleting the waiting marker partly because "V2 natively exposes permission.request.list, form.list and session.active"; AUD-M2 says those are HTTP API / client operation IDs, not `ctx` methods (`ctx.permission.list` takes `{ sessionID }`).
- Conflict (recorded, not resolved): invalid gate token at edit time - ARC-2 says deny (or throw Tool.Error in execute.before) so unattended runs never prompt; AUD-B2 allows deny "or keeping ask if human override is desired".
